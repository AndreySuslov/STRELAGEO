# СТРЕЛА

Текущий сайт: React 18, Vite, локальный Montserrat и локальные изображения. Две страницы: `/` и `/privacy/`. Данные разделов — `src/content.js`, компоненты — `src/components/`.

## Локальная работа

Требуется Node.js 22 или 24 и npm. Все команды из каталога `poehali/`:

```sh
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5175/.

## Проверки

```sh
npm run check
npm run test:sites
npm run build
npm audit
```

`check` проверяет синтаксис, неиспользуемые импорты, локальные ресурсы и ссылки данных. Сборка находится в `dist/client/`. Проверки кода не заменяют проверку интерфейса в браузере.

## Настройки Vercel

- Root Directory: `poehali`
- Framework: Vite
- Install Command: `npm ci`
- Build Command: `npm run build`
- Output Directory: `dist/client`

`vercel.json` содержит настройки сборки и маршруты для прямого открытия `/privacy` и `/privacy/`. Переменные окружения для текущего сайта не требуются. Само наличие конфигурации не публикует сайт.

Файлы `.openai/hosting.json`, `worker/index.js`, `scripts/prepare-sites-build.mjs` и `tests/sites-worker.test.mjs` сохранены для совместимости с Sites. На Vercel отдаётся только `dist/client/`.

## Исходные материалы

Сайт восстановлен из выбранного пользователем проекта Poehali и доработан по Figma. Оригиналы, архивы и снимки проверок хранятся локально; `.gitignore` исключает их из загрузки. Старые варианты в корне workspace не являются текущим приложением. При публикации выбирать именно `poehali/`.

Публикации блога ведут на четыре конкретные статьи Хабра и Дзена. Ссылки открываются в новой вкладке с `noopener noreferrer`. Форм регистрации и платежей нет; связь — через `mailto`, копирование адреса выполняется локально.

Текст `/privacy/` предоставлен владельцем. В нём сохранена фраза о Tilda; текущая реализация работает на React/Vite. Перед публичным запуском владельцу нужно уточнить эту формулировку.
