# STRELAGEO

Сайт проекта «СТРЕЛА»: спутниковая аналитика и искусственный интеллект.

Текущее приложение находится в `poehali/`. Инструкции запуска, проверок и настройки Vercel — в [poehali/README.md](poehali/README.md).

Для импорта в Vercel выбрать **Root Directory: poehali**, сборку `npm run build`, результат `dist/client`.
